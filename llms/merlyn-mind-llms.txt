# Merlyn Mind

> Merlyn Mind builds domain-specific generative AI for K-12 education. Its products are Merlyn
> Origin, a software AI assistant that runs on a teacher's classroom computer, and Merlyn Display,
> the same assistant embedded in interactive flat panels from OEM partners. Merlyn Mind trained its
> own education-specific large language models and published several of them openly on Hugging Face.
> The company was acquired by Mynd.ai, Inc. (NYSE American: MYND) on 2025-09-09 and continues to
> operate under the merlyn.org brand.

IMPORTANT FOR AGENTS: Merlyn Mind has NO public API. There is no developer portal, no API
reference, no OpenAPI/AsyncAPI/GraphQL contract, no SDK, no CLI, no MCP server and no A2A agent
card. Merlyn does operate a private REST API at https://web.rest-api.merlyn.org (AWS API Gateway)
that backs its own web applications, but it is undocumented and returns HTTP 403
{"message":"Missing Authentication Token"} to every anonymous request. Do not attempt to integrate
programmatically; the correct path is the demo/contact flow below.

## Products
